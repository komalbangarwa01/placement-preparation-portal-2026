# Placement Pal

Create a responsive Placement Preparation Portal using HTML, CSS, and JavaScript.

Create:

- Landing page

- Navigation bar

- Dashboard page

- Dark/Light mode toggle

- Responsive design

- Modern UI with cards and animations

Dashboard should display:

- Total Tests Attempted

- Average Score

- Strong Topics

- Weak Topics

- Recent Activity

Store all user data in Local Storage.

Use separate files:

index.html

style.css

script.js
